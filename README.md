# CivicConnect – Smart Civic Issues Reporting

Hackathon-ready frontend prototype.

## Features
- Citizen civic issue reporting
- Category, location and seriousness
- Browser GPS option
- Optional evidence photo
- Automatic report ID
- Report tracking with timeline
- Authority dashboard sorted by priority
- Status updates
- English, Telugu and Hindi selector
- Responsive mobile UI
- Browser localStorage for demo data

## Run
Simply open `index.html` in a browser.

Or run:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## GitHub
Upload `index.html`, `style.css`, `script.js`, and `README.md` to your `CivicConnect` repository.

## Note
This is a frontend prototype. A production version should add a secure backend/database, authentication, authority accounts, secure image storage and a real map/geocoding service.
